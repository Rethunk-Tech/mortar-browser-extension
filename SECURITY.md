# Security policy

The licence is in [`LICENSE`](LICENSE). The extension runs only on www.nexusmods.com, talks only to the Mortar app on the same computer through native messaging, and makes no other network requests.

## Reporting a vulnerability

Do not open an issue for a security report. Use GitHub's private vulnerability reporting on this repository, or email <opensource@rethunk.tech>, with a description, the affected files or version, the browser and Mortar versions in use, steps to reproduce, and the impact.

## Supported versions

Only the latest release is supported; fixes ship in a new release, not as patches to older ones.
